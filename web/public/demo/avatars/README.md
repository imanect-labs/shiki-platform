# デモ用の顔写真

`/messages`（Phase 14 の UI モック）で使う仮のプロフィール画像。

- **実在の人物ではない。** すべて生成モデル（StyleGAN 系）が作った顔で、
  モデルや同意の要る写真を避けるためにこれを選んでいる。
- 160x160 の JPEG。表示は最大 32px なので 2〜3x の解像度に足りる。
- ファイル名は `crates/messaging` の利用者 id ではなく、モックの
  `web/src/lib/messages-mock.ts` の `MEMBERS[].id` に対応する。
- **実装が入ったら消す。** 本番の顔写真は利用者のプロフィールから来る。
