生成: docs/events/bench/outbox-pool-bench.sh（scan / jobs / emit / mixed を順に実行した出力を連結。NOTICE 行は除去）。
機材: docker の PostgreSQL 16.15（Alpine）・既定設定・4 vCPU を他のビルドと共有（loadavg 4〜15）。絶対値ではなく伸び方を見ること。
emit の WAL/イベントは pg_current_wal_lsn（クラスタ全体）の差分なので、同居 DB の書込を含む上限値である。
実行時刻: emit / mixed は 10:24〜10:29Z、jobs は 10:41Z、scan は 11:02Z（休眠テナントの SSE poll を足した最終版のスクリプトで再実行）。
emit / mixed / jobs の計測ロジックは最終版と同じ。最終版で変えたのは安全柵（current_database の照合）と、mixed の pid ごとの wait だけ。
